## 5. Що з цього випливає (для обговорення)

- Масштаби η механічних компонентів — 10⁴–10⁵ год; поточні параметри моделі
  дають MTBF вузлів 2.3–6.9 год (див. Р16).
- Типові β для зносових механізмів — 1.2–2 (підшипники, ремені, двигуни,
  редуктори), для електроніки — ≤ 1. Це обґрунтовує класи і діапазони для
  аналізу чутливості (β ∈ {1; 1.5; 2.5; 3.5} покриває типові і верхні значення).
- Частка браку для FDM у неконтрольованих умовах — до ~19% маси матеріалу; у
  виробничих умовах очікується менше — використовуємо як верхню межу діапазону.
