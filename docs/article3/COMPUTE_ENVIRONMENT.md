# COMPUTE_ENVIRONMENT.md — обчислювальні середовища Статті 3

Офіційні серії (числа, рисунки, таблиці статті) — середовище **L** (локальне,
автор). Пілоти, налагодження, діагностика і контрольні копії для перевірки
відтворюваності — середовище **C** (хмарне середовище асистента).
У `runs_index.md` для кожного прогону вказується середовище (L/C).

| | L — локальне (офіційні серії) | C — хмарне (пілоти, контроль) |
|---|---|---|
| Процесор | Intel Core i5-9600K @ 3.70 GHz (6 ядер) | Intel Xeon @ 2.10 GHz, 2 vCPU |
| ОС | Windows 10 (10.0.19045) | Linux 6.18 |
| Python | 3.14.0 | 3.13.16 |
| NumPy | 2.4.0 | 2.5.3 |
| SciPy | 1.18.1 | 1.18.1 |
| PyTorch | 2.10.0 (CPU) | 2.14.1 (CPU) |

Зафіксовано: 2026-10-17.

## Відтворюваність
- Симулятор (NumPy, окремі генератори на кожну пару «вузол, процес», Р6) —
  детермінований за seed.
- Навчання нейромережі (PyTorch) не гарантує побітової відтворюваності між
  різними процесорами й версіями бібліотек; порівняння L і C на тих самих seed
  використовується як перевірка відтворюваності на рівні висновків.
