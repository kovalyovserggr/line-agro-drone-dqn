# Чернетка Статті 3 (Markdown)

Робочий текст статті англійською, по розділах. Фінальна збірка — DOCX у шаблоні MDPI *Machines*.

| Файл | Розділ | Стан |
|---|---|---|
| 02_methods.md | 2. Materials and Methods | чернетка v0.1 (2026-10-21) |
| 03_results.md | 3. Results | після заморожування результатів (Р50) |
| 04_discussion.md | 4. Discussion | після Results |
| 01_introduction.md | 1. Introduction (з оглядом літератури) | останнім, разом з анотацією |

Позначки в тексті:
- `[REF: …]` — посилання, яке треба додати (лише першоджерела з DOI);
- `[CHECK: …]` — факт для звірки з кодом або логами;
- `[AUTHOR: …]` — рішення чи формулювання для автора;
- `[TODO: …]` — таблиця чи число, яке генерує скрипт.

Позначки рішень (Р…) у фінальному тексті прибираються. Кожне число з результатів звіряється скриптом
(WORKFLOW_CHECKLIST, п. D).
